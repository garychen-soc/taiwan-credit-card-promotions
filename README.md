# 刷卡活動登錄雷達

整理台灣銀行官方信用卡活動，優先呈現需要登錄的時間點，並提供活動期間與登錄期間的一鍵行事曆功能。

目前資料來源：

- 星展銀行信用卡活動頁與官方網購活動明細
- 國泰世華 CUBE 活動專區與官方公開結構化資料
- 中國信託 LINE Pay 卡官方優惠一覽與六大點數生活圈
- 永豐銀行信用卡「刷卡享優惠」官方活動清單
- 上海商銀信用卡官方熱門活動清單與活動明細
- 王道銀行活動頁的「簽帳金融卡」專屬分頁（排除存錢、貸款、投資理財）
- 元大銀行信用卡官方優惠活動清單與分頁明細
- 玉山銀行刷卡優惠公開 API 與官方活動明細
- 陽信銀行信用卡／簽帳卡官方活動索引
- 台中銀行信用卡官方卡友優惠與活動明細
- 凱基銀行信用卡官方活動清單、分頁與活動明細
- 華南銀行熱門優惠頁的「信用卡」專屬分頁（排除存款/外匯、基金/投資、保險、貸款、其他）
- 台北富邦銀行卡友優惠完整分頁與活動明細
- 台新銀行 A–I 九大信用卡優惠分類、分頁資料與活動明細
- 第一銀行指定信用卡優惠入口（逐分類讀取官方 REST，不需要瀏覽器）
- 彰化銀行信用卡優惠入口的美食、購物、旅遊與其他四大分類
- 聯邦銀行七個官方活動 catalog，另將 `hotOrder` 聚合標記為強打優惠
- 兆豐銀行官方優惠 API 中標示「需登錄」且仍有效的活動與明細

## 網站功能

- 今日、明日活動登錄快速檢視
- 重點、高回饋、需登錄、即將開始、即將結束、銀行、分類等多維篩選
- 每筆活動列出銀行、期間、摘要、登錄時間與官方來源
- 明確標示登錄與消費先後、可否先消費後登錄、是否每期重登錄；官方未說明時顯示「未確認」，不自行推測
- 「需人工確認」涵蓋需登錄但無時點、活動截止日未知、登錄時點超出活動期間與視窗重疊；來源健康區同步顯示各銀行登錄時點覆蓋率
- 活動期間可加入 Google Calendar；登錄提醒事件固定為登錄開始起 15 分鐘，並可下載含 10 分鐘前提醒的 `.ics`
- 高回饋定義：回饋率至少 10%，或單筆／每期最高回饋至少 NT$500
- 指定入口失效時，只在銀行官方網域尋找替代網址，並輸出警示
- 已收錄活動保留清單指紋與結構化內容；清單未變更時直接沿用，避免重複讀取明細
- 首頁先載入小於 100 KB（gzip）的登錄活動索引；瀏覽完整清單時才載入各銀行目錄，展開活動條件時才載入條款原文
- 手動、每週與每月更新共用程序鎖，同時間只允許一個更新寫入資料
- 發布前執行覆蓋率防護；大量來源失敗、系統性 DNS 失敗、活動數災難性下降，或任一來源相較上一版下降超過 40% 時，只寫診斷報告並保留上一版網站；全站跌幅會排除沿用舊快照的 fallback 活動

## 架構

```text
銀行官方頁面
  └─ 固定規則擷取器（Python 標準函式庫）
       ├─ 官方網域與重新導向檢查
       ├─ 已收錄活動快取（官方條款作為解析輸入、清單指紋、30 天定期重驗）
       ├─ 活動、回饋、登錄時段標準化
       ├─ docs/data/promotions.json（首屏登錄索引）
       ├─ docs/data/banks/*.json（各銀行完整活動目錄）
       ├─ docs/data/activities/*.json（展開時載入的條款原文）
       └─ reports/latest.json（本機更新報告，不發布）

docs/
  └─ 純靜態 HTML、CSS、JavaScript
       └─ GitHub Actions → GitHub Pages
```

正常更新不使用生成式模型：先讀取官方活動清單，再以清單指紋比對已收錄活動。未變更且仍在 30 天重驗週期內的活動不再讀取明細，但每次都會以目前版本的解析器重新處理公開明細檔保存的官方條款原文；因此登錄時間、條款分段與條件不變式的解析修正可在下一次更新立即套用，不必等快取過期。回饋與分類仍保留各銀行 adapter 的結構化結果，避免條款中的利率或示例百分比被誤當成回饋。活動開始或結束日前後 3 天仍強制重驗；只有新活動、清單變更、快取到期、來源失效或規則無法確認時，才重新讀取官方明細或需要人工／AI 檢查，兼顧正確性、銀行負載與 token 成本。`data/activity_cache.json` 只保存指紋與最後檢查時間，不複製活動內容。

陽信指定入口目前會對自動化請求回傳 Cloudflare 403；網站會顯示來源警示並沿用已驗證的官方索引快照，不會把技術性阻擋誤判為網址失效，也不會在未確認前擅自改用非官方來源。

## 本機更新與驗證

```bash
PYTHONPATH=src python3 scripts/update_data.py
PYTHONPATH=src python3 -m unittest discover -s tests -v
node --check docs/assets/app.js
python3 scripts/validate_public_artifacts.py
python3 scripts/automation_summary.py
```

`scripts/automation_summary.py` 讀取 `reports/latest.json` 產生 Slack 摘要；若發布防護阻擋候選資料，會明確回報網站仍保留的上一版筆數，避免排程誤稱更新成功。

## 安全邊界

本專案只讀取公開官方資訊，不登入銀行帳戶、不替使用者執行活動登錄，也不收集卡號或個人資料。實際名額、資格與回饋仍以銀行官方公告為準。
